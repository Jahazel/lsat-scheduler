# Screenshot extraction alternatives

Research for [issue 72](https://github.com/Jahazel/lsat-scheduler/issues/72), checked October 1, 2026, America/Chicago. After this comparison, the user accepted a $10 monthly extraction pilot ceiling and manual-entry fallback. Retaining Haiku is the current recommendation; no provider switch was selected. See the [decision record](issue-72-decisions.md). No application edits, installations, provider changes, or paid calls were made. These sources establish capabilities and published terms, not accuracy on this app's screenshots.

The current [extractor](../../src/lib/claudeExtract.ts) asks Claude Haiku 4.5 to associate visible 7Sage Logical Reasoning labels with percentages or explicit HIGHEST flags. That association matters as much as recognizing the text. The [review component](../../src/components/AnalyticsReview.tsx) permits corrections and added rows after extraction, but currently hides that editor until extraction succeeds. A complete manual fallback would need an entry path and a decision about snapshot provenance and approval.

## Decision implications

Recommendation, based on integration effort rather than a measured accuracy advantage: keep the current model provisionally, add a complete manual fallback, and compare paid Gemini plus one OCR/parser approach on the same consented or synthetic screenshots before switching. Compare exact row labels, percentage values, HIGHEST association, missed/extra rows, correction time, latency, and retry cost. Include cropped images, small text, mobile screenshots, themes, and invalid inputs. A lower token price does not establish lower cost per successfully confirmed snapshot.

For scale only, 3.5 Flash-Lite with 3,000 billed input tokens and 1,000 billed output tokens costs $0.0034 per attempt, or $3.40 per 1,000 attempts. This is arithmetic using its published rates, not a measured screenshot estimate. Vision's paid OCR rate is $0.0015 per image for one feature, before parser/hosting costs and retries. Local OCR/manual entry have no model API charge. Free allowances are not production spending controls or availability guarantees.

Every hosted alternative still needs handler authentication, upload/output validation, shared quota accounting, bounded retries/concurrency, an emergency stop, and an application budget cutoff. Changing providers does not resolve those issue-72 requirements.
