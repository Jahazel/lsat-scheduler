# Component looks

Vitest runs in jsdom, which computes no styles, and lint refuses class-name checks in `src/**/*.test.{ts,tsx}`. These looks are proved only here. Run this recipe when a change touches `src/components/ui/`, `FOCUS` or `MOTION` in `src/components/ui/classes.ts`, the test dock, the workspace switcher, the nav tabs, the check-in lines, the screenshot file rows, the phone classes in `src/app/dashboard/upload/WeeklyUpload.tsx`, or the failure toast (`src/components/FailureNotice.tsx`, `src/lib/callAction.ts`).

Read each value with `getComputedStyle` in a short read-only `page.evaluate`. Colour and outline transitions run for up to 200 ms, so wait about 400 ms after a focus or state change before reading. Reach keyboard focus with `Shift+Tab` then `Tab` from the control, so `:focus-visible` matches. Colours: accent `rgb(18, 58, 148)`, danger `rgb(240, 82, 79)`, danger ink `rgb(194, 53, 50)`, smoke `rgb(92, 92, 92)`, ink `rgb(10, 10, 10)`, vellum line `rgb(228, 228, 228)`.

## Entry points

- `looks-focus-ring`: on `/login`, the `Email` textbox and the `Continue with Google` button; on `/signup`, the consent checkbox; on `/dashboard/upload`, the `Current score` textbox, the label around the checked `Screenshots` radio, and the `Logical Reasoning screenshot` drop zone. Each focused control shows a solid 2 px accent outline 2 px outside it. The focused checkbox's border is ink. The checked switch option's label has a white `background-color` (`rgb(255, 255, 255)`); the unchecked one's is transparent.
- `looks-disabled-button`: on `/dashboard/upload` before any analytics, `Read my screenshots` is disabled with `opacity: 0.4`.
- `looks-field-error`: type `190` in `Current score` and leave it. The box has `aria-invalid="true"` and a danger ink border.
- `looks-drop-zone`: dispatch `dragover` with a `DataTransfer` holding a PNG on the `Logical Reasoning screenshot` zone. It reads `Drop to add it`, with an accent border and an accent tint background. Choose a GIF in `Reading Comprehension screenshot file`: the zone has `data-state="error"` and a danger ink border.
- `looks-file-row`: stub `**/api/analytics/extract` with `page.route` to reach each read failure. The fake extractor cannot return them. Use 503 for a lost connection, 502 for an unreadable screenshot, and 504 for a timeout. On `/dashboard/upload`, choose both analytics screenshots and click `Read my screenshots`. On `/onboarding` with a `--not-onboarded` student, finish Goal and Week, then choose the Logical Reasoning screenshot. On both pages, `Connection lost. Your file is still here.` is smoke text on a row with a vellum line border. The unreadable and timed-out rows have a danger border and danger ink text. Their text is `Couldn't read that screenshot. Try again or a clearer image.` and `Reading took too long and stopped. Try again.` on the upload page, or `We couldn't read the rows in it.` and `Reading took too long and stopped.` in onboarding. Each stubbed reply logs one failed request and one console error; no others are expected.
- `looks-phone-rejection`: at 390 px, choose both analytics screenshots and click `Read my screenshots`. The `Screenshots` summary shows. In the first `Replacement for <file>` input, choose `huge.png`, 5 × 1024 × 1024 zero bytes typed `image/png`. The browser cannot decode it, so it cannot shrink it; a real large screenshot is shrunk and read with no message. `That file is 5.0 MB. Choose one that is 4 MB or less.` is visible on the full file row, inside the viewport, and the `Screenshots` summary heading is gone.
- `looks-phone-rejection` in a practice-test week: reach one as an Admin as [weekly-schedule.md](weekly-schedule.md) says (`Next Monday`, approve a sample, then the week strip's `Sa <day>, move to …` button), open `/dashboard/upload`, and require `Plan next week`. At 390 px, choose two analytics screenshots whose names differ from the fixtures, such as `lr-analytics.png` and `rc-analytics.png`, then all four `pt158-s*.png` fixtures in `All 4 section screenshots file`, and click `Read my screenshots`. The `Screenshots` summary shows and the `Practice test review` heading is hidden. In the first `Replacement for pt158-s2.png` input, choose `huge.png`. The section row reads `We couldn't read this screenshot` over `huge.png` with the 5.0 MB message inside the viewport, the `Practice test review` heading is visible again, and the `Screenshots` summary heading is gone. An analytics file named `pt158-s2.png` would take the replacement instead, because its row comes first.
- `looks-offline-toast`: signed out at 390 px, open `/forgot-password` and wait for `networkidle`. Type an email, call Playwright `context.setOffline(true)`, and click `Send reset link`. A `role=alert` toast reads `No connection. Check your signal and try again.`, with no `Error code`, 12 px above the bottom of the viewport and 366 px wide. The drive records one failed `POST /forgot-password` with `net::ERR_INTERNET_DISCONNECTED` and one matching console error, and `app.log` gets no server error. The Email box is empty afterwards, so type it again. Call `context.setOffline(false)` and click `Send reset link`: `Check your email` shows and the toast is gone. Next's route announcer is also a `role=alert`, so check the toast by its text. In a dev run, the Next dev badge covers the toast's left edge; a production build has no badge.
- `looks-current-marks`: as an Admin, open the workspace switcher. The current option's name has `font-weight: 600` and the other has 500. On This week, the current `This week` tab has `aria-current="page"` and `font-weight: 500`; the other tabs have 400.
- `looks-check-in`: approve a Sample analytics snapshot (see [Admin](admin.md)) and tick the first line on This week. Its label is smoke with `text-decoration-line: line-through`. An open line is ink with no line.
- `looks-progress-bar`: on that This week, the pace status (`<n> behind`, `<n> ahead` or `On pace`) ends at the bar's right edge. `Today` sits on its own line below the bar.
- `looks-past-days`: in the expanded Test controls, move to Thursday. Earlier days read `Past` in visible text (not `sr-only`) and have `opacity: 0.5`. Today has `opacity: 1`.
